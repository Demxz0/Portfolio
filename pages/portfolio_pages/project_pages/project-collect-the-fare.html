Collect the Fare

UnityRunner3DMobileInternship

Overview

Collect the Fare is a 3D mobile game I worked on for 3 months during my internship at Dimensions game studio. It started as a 2-week intern game jam and evolved into an Egyptian microbus dodging traffic illegally, Subway Surfers-style. First time using Unity, first time working in 3D.

Play the game

I do not own this game

2 weeks jam

Taif (my teammate in the jam) suggested an isometric runner, I suggested a panda/bamboo theme. The gameplay is switching between two roads, collecting bamboo, with some levels using a memory pattern puzzle. I learned Unity basics on YouTube beforehand, then split roles with Taif, she did art integration, roads, and bamboo spawning, I did player movement, camera, and the puzzle system.

Taif was more like a supervisor for me, she refactored my all-in-one player controller into four separate scripts (Player, PlayerMovement, PlayerHealth, PlayerInput), I learned a lot just watching how she restructured it.

Full Development

Our game was chosen to keep developing, reworked into a Subway Surfers-style runner. Samer became my supervisor. The concept shifted to an Egyptian microbus illegally dodging obstacles.

I was treated like a full employee. I was added to the studio's GitHub org and to Jira, where I ran my own scrum/kanban tasks for the first time.

The team showed me the importance of using design patterns and scriptable objects during the developments so a lot of logic i made was refactored especially in first month.

Also ideas were changing during development, so i worked on lots of things then got cancelled like the slow down mechanic.

Pigeon fly-away

My Impact & Decisions

Instead of copying Subway Surfers' generic poof-and-go continue effect, I tied it to the game's context: the van stalls briefly after the crash, then suddenly speeds off. I built it with tweens and added matching vroom/drift SFX into an existing data-driven audio system without disrupting it.

Lessons Learned

  • Learned Unity and 3D concepts from the ground up
  • Learned proper Git branching and team collaboration
  • Learned to test in isolation using temporary scenes/scripts
  • Learned spawning/pooling systems and real software architecture (singletons, scriptable objects, event bus, state machine, pooling, interfaces)
