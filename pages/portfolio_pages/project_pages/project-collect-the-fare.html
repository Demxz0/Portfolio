Collect the Fare

Unity C# 3D Mobile

Overview

Collect the Fare is a 3D mobile game I worked on for 3 months during my internship at Dimensions game studio. It started as a 2-week intern game jam and evolved through two full concept pivots into an Egyptian microbus dodging traffic illegally, Subway Surfers-style. First time using Unity, first time working in 3D.

My Role and Responsibilities

Main screen UI, camera balance, obstacle logic, sidewalk prop spawning, the after-continue effect, and the passenger pickup/drop-off system. I was treated like a full employee — added to the studio's GitHub org and Jira, running my own scrum tasks.

Process & Breakdown

  • Main UI and camera balance
  • Obstacle and sidewalk prop spawning
  • Passenger pickup/drop-off system
  • After-continue effect (my custom addition)

Challenges and Problems Solved

  • Getting a pigeon fly-away animation in the prop system to trigger at the right moment — first real 3D animation work.
  • Passenger jump animations clipped through the bus model — fixed by shrinking passengers as they pass through.
  • Learned refactoring firsthand when my initial code had to be rewritten for better architecture by seniors.

My Impact & Decisions

Instead of copying Subway Surfers' generic "poof-and-go" continue effect, I tied it to the game's own fiction: the van stalls briefly after the crash, then suddenly speeds off. I built it with tweens and added matching vroom/drift SFX into an existing scriptable-object audio system without disrupting it.

Lessons Learned

  • Learned Unity and 3D concepts from the ground up
  • Learned proper Git branching and team collaboration
  • Learned to test in isolation using temporary scenes/scripts
  • Learned spawning/pooling systems and real software architecture (singletons, scriptable objects, event bus, state machine, pooling, interfaces)
